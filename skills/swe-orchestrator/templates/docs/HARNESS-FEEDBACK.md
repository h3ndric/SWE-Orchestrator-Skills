# Harness feedback: lessons for improving the team itself

This file is about **the orchestrator and its skills**, not about this product. Agents add an entry whenever the process went wrong or could be better (see the swe-orchestrator skill, references/harness-feedback.md). The owner can add one any time by saying "log a lesson: …".

A scheduled harness review collects new entries from every project and turns them into skill fixes, sent to the owner for approval. Entries are never edited or deleted once written; the review keeps track of what it has processed.
